# Нацконгресс — статический чек-лист

Разместить `index.html` в корне репозитория или папке публикации GitHub Pages. Сборка, сервер и зависимости не нужны. Можно открыть HTML локально.

Две вкладки: список задач и новая задача. 13 исходных пунктов, редактирование, чекбоксы выполнения и необходимости действий, фильтры, поиск. Приоритеты предварительные; неизвестные ответственные и сроки не назначены.

Данные хранятся в localStorage браузера, общей синхронизации нет. Используйте экспорт/импорт JSON для резервной копии и переноса. Очистка данных браузера удалит изменения. Для публикации нужен только index.html.
