# Нацконгресс — список задач

Публичная страница: https://dtufilin-alt.github.io/natcongress-tasks/

## Ветка shared-sync (подготовка, ещё не опубликована)

Список получает задачи из общего API. Изменения сохраняются в D1, список обновляется каждые 5 секунд. Проверка версии задачи защищает от перезаписи чужих правок. Удаление сохраняет запись в истории и запрещает восстановление устаревшим импортом.

Для запуска требуется заполнить config.js адресом развёрнутого Worker. Без него эта ветка не является рабочей заменой опубликованной страницы. Порядок размещения и ограничения: worker/DEPLOYMENT.md.

Прежний localStorage `natcongress-tasks-v1` не изменяется. Кнопки скачивания и переноса появляются, если в текущем браузере есть прежние задачи. Перед переносом создаётся JSON-копия и запрашивается подтверждение. Импорт не удаляет отсутствующие в файле задачи.

Пока переход не завершён, опубликованная версия main хранит изменения только в браузере пользователя.
