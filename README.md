# Нацконгресс — общий список задач

https://dtufilin-alt.github.io/natcongress-tasks/

Общие задачи хранятся в Cloudflare D1 через Worker. Доступ — всем по ссылке, без входа. Список обновляется каждые 5 секунд при открытой вкладке. Версия каждой задачи защищает от перезаписи чужих изменений.

При первом переходе откройте сайт в браузере, где вносились прежние правки, и нажмите «Перенести мои задачи». Перед переносом скачивается резервный JSON. Прежний localStorage не изменяется. Без переноса общий список может быть пустым. Импорт добавляет и обновляет задачи после подтверждения, но не удаляет отсутствующие в файле.

Исходники и workflow публикации backend находятся в ветке shared-sync. Секрет Cloudflare хранится только в GitHub Actions. config.js содержит только публичный адрес API.

Проверки: node --test tests/shared-api.test.mjs. История изменений хранится в таблице history, удаление использует tombstone.
